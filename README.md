# server-js
Простая реализация сервера PartyGDK на чистых веб-сокетах и стандартном веб-сервере Node.js.

> [!WARNING]
>
> Данная реализация сервера устарела и была заменена на [версию](https://github.com/PartyGDK/server-ts), написанную на TypeScript.

## Переменные среды
Сервер поддерживает задание переменных среды `HOST` и `PORT`. Они по приоритету находятся выше настроек в файле конфигурации.
